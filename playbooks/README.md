# 필요한 안내만 고르기

이 폴더는 과제 유형이나 현재 막힌 단계에 맞춰 읽는 선택 자료입니다. 처음부터 전부 읽거나 모든 절차를 수행할 필요는 없습니다. 실제 과제 README, 제출 조건, 최신 운영 규정이 우선합니다.

| 상황 | 읽을 파일 | 얻을 결과 |
|---|---|---|
| 전체 흐름 파악 | [180분 진행](180-minute-workflow.md) | 시간 배분과 단계별 완료 기준 |
| 무엇을 만들지 모호함 | [업무 담당자 질문](stakeholder-interview.md) | 사용자·문제·필수 조건 확인 |
| 표·CSV·집계·시각화 과제 | [데이터 분석](data-analysis.md) | 입력 점검, 처리 기준, 정확성 검증 |
| 화면·서버·API 과제 | [웹과 API](web-and-api.md) | 작동하는 사용자 흐름과 오류 처리 |
| 예측·분류·모델 과제 | [머신러닝](machine-learning.md) | 비교 기준, 데이터 분리, 적절한 지표 |
| 오류 수정이 반복됨 | [디버깅](debugging.md) | 재현 → 원인 확인 → 최소 수정 |
| AI가 맥락을 놓치거나 작업을 넘김 | [맥락과 인수인계](context-and-handoff.md) | 현재 상태를 복구할 기록 |
| 제출 전 설명 연습 | [구현 이해와 설명](explain-your-work.md) | 구조·이유·검증·한계를 자신의 말로 설명 |

## 기본 사용법

1. [180분 진행](180-minute-workflow.md)을 한 번 읽습니다.
2. 메모는 우선 [WORKLOG 양식](../templates/WORKLOG.md) 하나로 시작합니다.
3. 해당하는 과제 유형 안내 한 개를 고릅니다.
4. 막히는 단계가 생길 때 필요한 안내만 추가로 읽습니다.

## 읽기 전에

- 여기의 시간·질문·검증 수는 권장 운영 방식이며 공식 배점이나 필수 제출 목록이 아닙니다.
- 예시 데이터·기대 결과는 설명용입니다. 실제 실행 결과로 기록을 채웁니다.
- 시험 중 작성한 코드·데이터·메모·질문은 과제 작업 공간에 두고 공개 저장소에 올리지 않습니다.
- 후속 서술형에서는 해당 단계의 AI·복사·붙여넣기 제한을 따릅니다. 설명 연습은 허용된 과제 수행 단계에서 끝냅니다.
