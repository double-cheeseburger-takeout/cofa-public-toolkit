# 표·CSV·집계 과제

CSV는 쉼표 등으로 열을 구분한 표 파일입니다. 파일을 읽는 데 성공한 것과 올바른 의미로 계산한 것을 구분해야 합니다.

## 1. 입력을 먼저 확인

- 파일 위치, 인코딩, 구분자, 열 이름, 행 수를 확인합니다.
- 숫자·날짜·문자열이 어떤 형태로 저장됐는지 확인합니다.
- 누락값, 중복 행, 단위, 날짜 범위, 비정상 값을 확인합니다.
- 열의 의미와 집계 기준을 과제 설명·업무 담당자 답변에서 확인합니다.
- 원본을 보존하고, 필요하면 별도의 처리 결과를 만듭니다.

주의할 예:

- 00123은 앞자리 0을 보존해야 하는 식별자일 수 있습니다.
- 1,000은 천 단위 표기일 수 있어 CSV 구분자와 혼동하지 않아야 합니다.
- 빈칸이 0인지 미측정인지 알 수 없으면 임의로 같게 처리하지 않습니다.
- 시간대가 다른 날짜, 초·밀리초 단위가 다른 시간값은 직접 비교할 수 없습니다.

## 2. 전처리 정책 정하기

전처리는 계산 전에 데이터를 정리하는 작업입니다. 삭제·변환·채우기를 적용할 때 이유와 영향을 확인합니다.

| 문제 | 판단할 질문 | 확인할 영향 |
|---|---|---|
| 누락값 | 계산에 꼭 필요한 열인가? 다른 열의 누락까지 제외해야 하나? | 남은 행 수, 합계, 특정 집단의 편향 |
| 중복 | 행 전체가 같은가, 같은 사건을 가리키는가? | 제거 건수, 합계 변화 |
| 이상값 | 입력 오류인가, 실제 드문 사건인가? | 최댓값·분포·핵심 결론 변화 |
| 형식 오류 | 변환 불가 값을 어떻게 알릴 것인가? | 오류 건수, 제외 기준 |
| 단위 차이 | 기준 단위와 변환식이 무엇인가? | 작은 수치로 변환 검산 |

문제를 찾았다는 이유만으로 모두 삭제하지 않습니다. 과제 목적에 필요한 정책을 선택합니다.

## 3. 계산 기준 확인

- 합계·평균·비율 중 무엇이 업무 목적에 맞는지 확인합니다.
- 평균의 분모, 비율의 분자·분모, 제외 기준을 명시합니다.
- 그룹별 평균을 다시 단순 평균하면 표본 수가 다른 집단을 잘못 합칠 수 있습니다.
- 기간별 계산은 경계 날짜가 포함되는지 확인합니다.
- 환불·음수·0·중복의 의미를 정한 뒤 집계합니다.

가상 검산 예: 환불을 음수로 반영한다고 확인된 경우, 100 + 200 - 50 = 250입니다. 실제 데이터에서 같은 기준을 써야 하는지는 별도 확인합니다.

## 4. 의미 있는 검증

1. 손으로 답을 계산할 수 있는 작은 데이터와 결과를 비교합니다.
2. 전체 합계와 그룹별 합계의 합이 같은 기준에서 일치하는지 확인합니다.
3. 전처리 전후 행 수·합계·제외 건수를 확인합니다.
4. 빈 파일, 필수 열 누락, 숫자 변환 실패 중 중요한 사례를 확인합니다.
5. 필터를 적용한 표·요약·그래프가 같은 데이터를 사용하는지 확인합니다.

## 5. 그래프와 화면

- 제목, 단위, 기간, 필터 조건을 표시합니다.
- 값이 없는 경우와 값이 0인 경우를 구분합니다.
- 순서가 의미 있는 범주·날짜를 올바르게 정렬합니다.
- 일부 데이터만 표시했다면 그 범위를 드러냅니다.
- 색이나 모양만으로 중요한 의미를 전달하지 말고 텍스트도 사용합니다.

## 6. 설명 준비

- 어떤 열을 입력받아 무엇을 계산했나요?
- 누락값·중복값을 그렇게 처리한 이유는 무엇인가요?
- 처리로 인해 결과가 얼마나 달라졌나요?
- 계산이 맞는지 무엇으로 확인했나요?
- 데이터가 커지거나 형식이 바뀌면 어디서 문제가 생길까요?
