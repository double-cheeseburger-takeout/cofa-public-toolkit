확인한 내용:
- 입력 / 기대 결과 / 실제 결과

남은 문제:
- 영향 / 우선순위 / 다음 확인 방법

다시 시작할 때:
- 실행 방법 / 현재 상태 / 다음 작업


현재 결과물을 다음 관점에서 검토해줘.

- 필수 요구사항 중 빠진 것
- 실제로 틀린 결과를 만드는 입력
- 지금 수정해야 할 문제와 나중에 개선할 문제
- 제안하는 확인 방법

각 지적에는 코드나 실행 결과의 근거를 붙여줘.
