# Cofa Public Toolkit

**공개 저장소에 미리 올려두고, 허용된 평가 환경에서 가져와 사용할 수 있는 범용 AI 작업 도구 모음입니다.**

문제 정의 → 구현 → 실제 검증 → 설명 → 제출을 돕습니다. 특정 시험의 문제·정답·완성 앱은 포함하지 않습니다. Cofa·KRAFTON·SK하이닉스의 공식 배포물이나 승인 자료가 아닙니다.

## 바로 시작하기

1. 시험 전 공개 저장소 준비: [QUICKSTART_KO.md](QUICKSTART_KO.md)
2. 시험에서 AI가 먼저 읽을 지침: [AGENTS.md](AGENTS.md)
3. 시작 단계에만 읽을 Skill: [task-plan](skills/task-plan/SKILL.md)
4. 실제 판단·확인 기록: [WORKLOG 양식](templates/WORKLOG.md)
5. 도구가 필요할 때: [scripts 사용법](scripts/README.md)

처음부터 모든 파일을 AI에게 읽히지 마세요. 기본 지침과 현재 단계의 자료만 선택합니다. 실제 과제의 README, 제출 요구, 최신 운영 안내, 플랫폼 제한이 이 자료보다 우선합니다.

## 외부자료를 고를 때

[외부자료 시작 안내](external-resources/README.md)에 25종의 공개 저장소·공식 문서를 용도별로 정리했습니다. [전체 목록](external-resources/CATALOG.md)과 [상황별 요청문](external-resources/PROMPTS_KO.md)을 활용하세요. 필요한 자료만 읽으며, 추가 도구의 설치가 전제인 묶음은 아닙니다. 링크와 본문 확인일은 2026-10-31이며 Cofa 환경 호환성은 별도입니다.

## 무엇이 들어 있나요?

| 위치 | 용도 | 읽을 때 |
|---|---|---|
| AGENTS.md | 짧은 공통 작업 지침 | 시작 시 1회 |
| skills/ | 계획·검증·리뷰·인수인계·설명·제출 6개 절차 | 해당 단계 |
| playbooks/ | 데이터·웹/API·ML·디버깅 등 과제별 방법 | 관련 과제일 때 |
| prompts/ | 바로 사용할 작업 요청문 | 작업을 맡길 때 |
| templates/ | 요구사항·판단·테스트·출처·인수인계 양식 | 필요한 기록만 |
| scripts/ | Python 표준 라이브러리로 실행하는 로컬 도구 | 반복 점검을 줄일 때 |
| examples/ | 도구 사용을 익히는 작은 합성 데이터 | 시험 전 연습 |
| tests/ | 이 도구 모음 자체의 검증 | 시험 전 또는 도구 오류 확인 |

Skill은 AI가 특정 일을 수행할 때 읽는 절차 문서입니다. 이 ZIP은 Skill을 개인 계정에 설치하지 않습니다. 제공 Codex 버전에 상관없이 파일 내용을 직접 읽히는 방식으로 사용할 수 있습니다.

추가 자료는 필요한 단계에서만 읽어 주세요.
실행한 검증과 아직 확인하지 못한 사항은 구분해 주세요.

## 사용 조건

- 공개 저장소 이용·반입은 해당 평가의 규칙을 따릅니다. [RULES.md](RULES.md)
- 이번 준비 자료가 근거로 삼은 안내에서는 공개 상태를 2차 예선 결과 통지 전까지 유지해야 합니다.
- 개인 PC ZIP을 시험 화면에 업로드하는 절차가 아닙니다. 시험 전에 공개하고, 시험 환경에서 허용된 방법으로 가져옵니다.
- 시험 문제·입력 데이터·작성 답안·로그·결과물은 시험 환경에 둡니다. 이 공개 저장소로 다시 전송하지 않습니다.
- 이 자료는 실제 과제의 검증이나 합격을 보증하지 않습니다. tests/ 통과는 툴킷 자체의 동작 확인입니다.

## 최소 실행 환경

문서는 별도 설치 없이 읽을 수 있습니다. 도구는 Python 3.9 이상과 표준 라이브러리만 사용합니다. 제공 환경에 Python이 없으면 문서·양식만 사용하고, 이 툴킷 때문에 환경을 임의로 변경하지 마세요.

도구 17개 테스트와 Skill 6개 형식 확인 등 실제 확인 범위는 [VALIDATION.md](VALIDATION.md)에 정리했습니다.
