# 예제는 도구 사용법 확인용입니다

이 폴더의 데이터와 설정은 모두 이 저장소를 위해 새로 만든 합성 예제입니다. 실제 대회 문제·정답·참가자의 제출물은 포함하지 않습니다.

| 파일 | 확인할 내용 |
|---|---|
| `tiny_sales.csv` | 쉼표가 들어간 따옴표 필드, 양수·음수 금액. 금액 합계는 250입니다. |
| `tiny_sales_invalid.csv` | 중복 행 1개, 빈 금액, 날짜처럼 보이지만 형식이 다른 문자열, 열 수가 부족한 행. |
| `checks.example.json` | **이 도구 모음 자체의 테스트**를 실행하는 설정. 사용자 과제의 성공을 뜻하지 않습니다. |
| `checks.project.template.json` | 과제에 맞는 검증 명령을 직접 넣는 빈 설정. 빈 채로 실행하면 설정 오류가 나도록 했습니다. |
| `deliverables.example.json` | 파일 존재 확인 도구의 사용법 예시. 실제 과제 제출 목록으로 교체해야 합니다. |

CSV 진단기는 날짜의 업무 의미, 거래의 정당성, 환불 처리 기준을 추정하지 않습니다. `not-a-date` 문자열도 날짜 전용 검사 없이 일반 문자열로 보고합니다. 날짜 규칙·중복 처리·누락값 정책은 과제 조건에 맞춰 별도로 확인하십시오.

예제 명령은 [`../scripts/README.md`](../scripts/README.md)에 있습니다.
