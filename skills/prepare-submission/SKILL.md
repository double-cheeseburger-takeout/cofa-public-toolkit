# 제출 준비

실제 과제의 제출 지시와 남은 시간을 먼저 확인한다. 이 툴킷의 예시 파일명을 필수 제출 파일로 오인하지 않는다.

## 제출 조건을 대조한다

1. 요구된 파일·경로·형식이 있는지, 비어 있지 않은지 확인한다.
2. 안내된 실행 방법이 현재 파일에 맞는지 확인한다.
3. 핵심 흐름과 주요 결과를 실제로 다시 확인한다.
4. 테스트 결과·문서·코드가 현재 버전에 해당하는지 확인한다.
5. 필요한 출처·사용 방법·알려진 한계를 짧게 남긴다.
6. 필수 기능을 해칠 대규모 변경을 멈추고 제출 시간을 확보한다.

필요한 경우 로컬 파일 목록과 해시를 기록한다. 해시는 파일의 변경 여부를 비교하는 값이며, 정답 여부를 증명하지 않는다. 원본 지시서·데이터·감독 설정을 삭제하거나 수정하지 않는다.

## 남은 일을 분류한다

제출 차단 문제 → 필수 누락 → 잘못된 결과 → 중요한 검증 부족 순으로 우선한다. 선택 개선은 시간이 남을 때만 한다. 미완료 기능을 완료라고 문서화하지 않는다.

## 사람에게 확인할 내용을 전달한다

제출 대상, 실제 실행 결과, 알려진 한계, 화면에서 확인할 제출 완료 정보를 간단히 보고한다. 제출 버튼·후속 문항·감독 종료는 실제 화면 안내에 따라 응시자가 처리한다.

이 Skill은 플랫폼 제출을 자동화하지 않는다. 외부 저장소 전송이나 개인 PC로의 결과 반출을 수행하지 않는다.
