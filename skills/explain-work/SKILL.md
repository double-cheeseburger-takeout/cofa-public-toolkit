# 구현 설명 연습

현재 단계에서 AI 이용이 허용되는지 먼저 따른다. 후속 서술형에 AI가 답을 대신 작성하는 용도로 사용하지 않는다. 과제 수행 중 실제 구현을 이해하는 연습에 사용한다.

## 질문을 실제 구현에 연결한다

관련 파일·함수·데이터 처리·테스트를 읽은 뒤 한 번에 1~3문항을 낸다. 읽지 않은 구현을 가정한 질문을 사실처럼 제시하지 않는다.

질문 관점:

1. 입력부터 출력까지 어떤 순서로 처리되는가?
2. 이 구조·기술·데이터 처리를 택한 이유는 무엇인가?
3. 대안과 비교해 얻은 점과 포기한 점은 무엇인가?
4. 실제 확인한 범위와 결과는 무엇인가?
5. 어느 입력이나 상태에서 실패할 수 있는가?
6. 시간이 더 있다면 무엇을 먼저 확인할 것인가?

## 본인이 먼저 답하게 한다

질문에 대한 본인의 설명을 받은 뒤 코드와 대조한다. 틀린 부분은 해당 구현 근거로 설명하고, 부족한 개념은 짧은 예로 풀어준다. 정답 문장 암기를 목표로 삼지 않는다.

답변은 질문의 핵심부터 시작하고 구현 사실, 선택 조건, 확인 근거, 남은 한계를 필요한 만큼 연결한다. 일반론으로 실제 동작의 빈칸을 채우지 않는다.

## 마무리한다

설명하지 못한 핵심 2~3개를 남겨 과제 시간 안에 다시 확인한다. 확인하지 않은 성능 수치·테스트·결정 이유를 만들어 넣지 않는다. 모든 한계를 해결한 것처럼 쓰지 않는다.
