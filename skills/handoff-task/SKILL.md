# 작업 인수인계

이 절차는 작업 맥락을 넘기기 위한 것이다. 계정·키·문제·결과물을 외부로 보내지 않는다. 메모는 허용된 작업 공간 안에 저장한다.

## 먼저 현재 상태를 확인한다

현재 지시서, 변경 파일, 실행 명령과 최근 확인 결과를 읽는다. 기억만으로 완료 처리하지 않는다. 읽지 못한 파일은 확인하지 못했다고 표시한다.

## 짧은 인수인계 메모를 만든다

- 목표와 남은 시간
- 필수 조건별 완료/진행/미확인 상태
- 핵심 파일과 실행 방법
- 선택한 구조와 바꾸지 말아야 할 조건
- 실제 실행한 검증, 결과, 관련 기록 위치
- 현재 오류와 재현 방법
- 미확인 위험과 우선순위
- 다음에 할 구체적 행동 1~3개

가능하면 40~60줄 안에 정리한다. 전체 대화를 복사하지 않는다. 문맥 유지에 필요 없는 개인정보·원시 데이터를 넣지 않는다.

## 재개할 때

새 세션은 메모와 실제 지시서·관련 파일을 함께 읽는다. 메모가 오래됐거나 코드와 다르면 실제 상태를 확인하고 갱신한다. 완료된 일을 다시 구현하기보다 다음 미완료 항목부터 진행한다.

검증 결과를 복사해 새로 실행한 것처럼 날짜나 상태를 바꾸지 않는다. 필요한 경우에만 다시 실행한다. 기존 메모를 파괴하거나 과제 원본 지침을 덮어쓰지 않는다.
