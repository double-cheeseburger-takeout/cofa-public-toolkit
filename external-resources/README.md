# 외부자료: 여기서 시작하세요

**기본은 기존 toolkit + 현재 과제에 필요한 공식 문서입니다. 오류가 생기면 Superpowers의 오류 분석 문서, 제출 전에는 검증 문서를 보완 자료로 사용합니다.**

이 폴더는 25종의 공개 자료를 골라 놓은 링크 목록·적용 안내·요청문입니다. 조회 기준일은 2026-10-31입니다. 모든 자료의 설치나 모든 문서의 일괄 읽기를 요구하지 않습니다.

## 먼저 고르는 순서

1. 실제 과제의 README, 기존 코드, 필수 요구와 제출 방법을 확인합니다.
2. 표 데이터면 pandas, 예측 모델이면 scikit-learn, 기존 웹 앱이면 그 앱이 쓰는 React/FastAPI 등의 공식 문서를 고릅니다.
3. 검증은 과제 요구사항과 연결합니다. Python이면 pytest, FastAPI면 TestClient 예시를 참고할 수 있습니다.
4. 오류가 반복될 때만 Superpowers의 systematic-debugging, 완료 판단 전에는 verification-before-completion을 참고합니다.
5. 웹 화면 점검은 Vercel Web Interface Guidelines를 선택하고 응시자가 플랫폼 Browser에서 직접 확인합니다.

## 시험에서 AI에게 할 요청

현재 과제의 지침과 기존 환경을 먼저 확인해 주세요. 이 폴더의 catalog.json에서 현재 작업에 직접 필요한 자료를 최대 3개만 골라, 자료명과 필요한 이유를 짧게 설명해 주세요. 필요한 부분만 플랫폼의 허용된 방법으로 읽고 적용하세요. 기존 도구로 해결되면 추가 설치 없이 진행하세요. 실제 작업과 검증 결과는 시험 작업 공간에만 기록하세요.

## 범위와 조건

- 최신 운영 공지와 과제 지침이 이 자료보다 우선합니다. 제공 Codex를 업데이트하지 않습니다.
- 공개 자료는 시험 전 열어 확인할 수 있습니다. 시험 중에는 플랫폼 안의 AI를 통해 허용된 조회·Clone·다운로드 방법으로 활용합니다.
- 개인 PC 파일 업로드, Git Push, 문제·데이터·코드·결과물의 외부 전송, Computer Use는 사용하지 않습니다.
- MCP는 AI와 도구를 연결하는 방식입니다. 문서·코드를 읽기만 하는 데 MCP 설치가 필요한 것은 아닙니다.
- 공개 저장소는 안내된 결과 통지 시점까지 공개 상태를 유지해야 합니다. 제3자 저장소의 향후 상태는 작성자가 보장할 수 없으므로 실제 사용 시 접근 상태를 확인합니다.
- 이 묶음에는 타인의 저장소 원문, 공식 시험 가이드 원본, 비공개 문제와 해답을 복제하지 않았습니다. 원문을 복사해 재배포할 때는 그 자료의 LICENSE와 표시 조건을 확인합니다.
- 자료 링크와 문서를 검토했으며, Cofa 환경에서 외부 도구의 설치·호환성을 시험한 것은 아닙니다.
