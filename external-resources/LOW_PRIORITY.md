# 신규 도입 우선순위가 낮은 자료

다음 판단은 180분 시험에서 처음 도입하는 상황을 기준으로 합니다. 도구의 일반적인 품질이나 장기 프로젝트의 유용성을 부정하는 뜻은 아닙니다.

## Superpowers 전체 활성화

https://github.com/obra/superpowers

기본 과정에는 설계 확인, Git 작업 공간 분리, 세부 계획, 테스트 선작성, 하위 에이전트 검토 등이 묶여 있습니다. 기존 toolkit과 겹치는 부분이 많으므로 이번 준비에서는 오류 분석과 검증 문서를 필요할 때 참고하는 방식부터 권합니다. 최신 README의 설치 방식이 제공 Codex에서도 지원된다고 보장하지 않습니다.

## OpenAI Skills의 예전 설치 안내

https://github.com/openai/skills

확인 시 README는 deprecated(기존 배포 경로로서 더 이상 권장하지 않음)를 표시하고 현재 예시를 https://github.com/openai/plugins 로 안내합니다. 과거 문서가 모두 작동하지 않는다는 뜻은 아닙니다. 최신 자료의 설치를 위해 제공 Codex를 바꾸지 않습니다.

## GSD / BMad

- https://github.com/open-gsd/gsd-core
- https://github.com/bmad-code-org/BMAD-METHOD

개발의 계획·구현·검토 절차를 관리하는 도구들입니다. 별도 설치·초기화와 사용법 학습이 필요해 이번 시험 당일 새로 도입할 우선순위는 낮게 두었습니다. BMad에는 작은 작업용 경로도 있으므로 대형 프로젝트 전용이라고 단정하지 않습니다.

## Context7

https://github.com/upstash/context7

현재 setup은 인증과 설정 파일 변경을 포함합니다. 허용된 연결이 이미 있으면 일반 기술 문서를 조회할 때 선택하고, 연결이 없다면 공식 문서 직접 읽기를 우선합니다. 문제·제공 데이터·코드·로그를 외부 질의에 넣지 않습니다.

## Work Practice Lab

https://github.com/JakeB-5/work-practice-lab

지원 환경에서 사전 연습할 때 쓰는 독립 앱입니다. 기본 설치의 네이티브 Windows 미지원과 Linux 전체 흐름 미검증이 명시되어 있습니다. 자체 모의 점수는 공식 시험의 점수 예측치가 아닙니다. 시험 환경 내부 실행용으로 추천하지 않습니다.

## 공개 문서 Skill의 일괄 복제

https://github.com/anthropics/skills

README는 docx/pdf/pptx/xlsx를 다른 예제와 구분하고 개별 라이선스를 안내합니다. 공개되어 있다는 사실만으로 전체를 같은 조건으로 재배포할 수 있다고 가정하지 않습니다. 이번 묶음에는 설명과 원문 링크만 담았습니다.

## 이번 목록에 넣지 않은 실행 방식

외부 AI 계정·개인 키를 이용한 답안 생성, 외부 서비스에 과제 자료 업로드, Git Push·클라우드 배포·동기화, Computer Use와 브라우저 자동 조작은 이번 안내의 사용 범위에 포함하지 않습니다. 공개 코드라는 이유로 시험 제한이 없어지는 것은 아닙니다.
