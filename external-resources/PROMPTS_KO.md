# 상황별 AI 요청문

실제 과제에 맞게 바꾸어 쓰는 범용 요청문입니다. 후속 서술형 답변은 본인이 직접 작성하며 AI를 사용하지 않습니다.

## 자료를 처음 고를 때

```text
현재 과제의 요구사항, 기존 코드, 설치된 도구를 먼저 확인해 주세요. external-resources/catalog.json에서 지금 필요한 자료를 최대 3개만 고르고 이유를 설명해 주세요. 자료 전체를 읽거나 도구를 전부 설치하지 말고, 과제에 필요한 부분만 참고해 구현해 주세요.
```

```text
pandas 공식 문서 중 현재 데이터 처리에 필요한 부분을 참고해 주세요. 읽은 행 수, 열 이름과 자료형, 누락값, 중복, 표 결합 전후 행 수와 주요 합계를 확인해 주세요. 처리 기준의 이유와 실제 확인한 결과를 짧게 기록해 주세요.
```
