# 기록 양식 선택

기본은 [WORKLOG.md](WORKLOG.md) 하나입니다. 별도 문서가 실제로 도움이 될 때만 아래 양식을 추가합니다. 파일명은 예시이며 실제 과제의 제출 지침이 우선합니다.

| 양식 | 필요한 경우 |
|---|---|
| [WORKLOG.md](WORKLOG.md) | 목표·결정·검증·다음 일을 한곳에 기록 |
| [REQUIREMENTS.md](REQUIREMENTS.md) | 요구사항이 많거나 여러 역할이 나눠 구현 |
| [DECISIONS.md](DECISIONS.md) | 결과에 영향을 주는 선택이 여러 개 생김 |
| [TEST_PLAN.md](TEST_PLAN.md) | 중요한 입력·오류 사례를 미리 정리 |
| [TEST_REPORT.md](TEST_REPORT.md) | 실제 실행 결과와 실패를 정리 |
| [HANDOFF.md](HANDOFF.md) | 다른 역할·세션이 작업을 이어받음 |
| [SUBMISSION_README.md](SUBMISSION_README.md) | 실행·제출 안내가 필요 |
| [SOURCE_LOG.md](SOURCE_LOG.md) | 외부 공개 자료의 사용 범위 기록 |

## 사용 원칙

- 원본 양식은 범용 자료로 유지하고, 실제 기록은 과제 작업 공간의 별도 위치에 작성합니다.
- 실제 과제 README나 제공 문서를 덮어쓰지 않습니다.
- 기록을 만들기만 했다고 요구사항·검증이 충족되지는 않습니다.
- 예시와 대괄호를 실제 내용으로 채우되, 모르는 내용은 미확인으로 남깁니다.
- 시험 중 작성한 기록은 시험 환경 안에 보관합니다. 공개 저장소로 보내지 않습니다.
- 제출에 필요 없는 양식은 생성하지 않아도 됩니다.
