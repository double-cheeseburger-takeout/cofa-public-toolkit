# 단계별 요청문

현재 단계에 필요한 요청 하나만 사용합니다. 대괄호는 실제 내용으로 바꾸고, 불필요한 항목은 지웁니다. 이 요청문은 시험 규정이나 과제 지시를 바꾸지 않습니다.

| 단계 | 파일 |
|---|---|
| 처음 시작 | [start.md](start.md) |
| 요구사항 확인 | [clarify.md](clarify.md) |
| 범위를 정해 구현 | [implement.md](implement.md) |
| 독립적으로 검토 | [review.md](review.md) |
| 오류 원인 찾기 | [debug.md](debug.md) |
| 맥락 정리·인수인계 | [handoff.md](handoff.md) |
| 구현 설명 연습 | [explain.md](explain.md) |
| 제출 전 확인 | [finalize.md](finalize.md) |

## 사용 전

- AI가 실제 과제 README와 제공된 프로젝트 지침을 읽도록 합니다.
- 모든 파일을 한 번에 입력하지 않습니다. 필요한 안내와 양식만 읽게 합니다.
- 개인 계정·API 키·외부 AI·금지된 도구를 사용하도록 요청하지 않습니다.
- 설명 연습 요청은 AI 사용이 허용된 과제 수행 단계에서만 사용합니다.
- 요청문의 표현을 그대로 사용했는지보다 실제 결정과 확인이 이루어졌는지가 중요합니다.
