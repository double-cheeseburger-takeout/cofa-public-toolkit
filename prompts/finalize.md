# 제출 전 확인 요청

~~~text
남은 시간은 [분]입니다. 실제 과제의 제출 지침을 기준으로 최종 확인해주세요.

확인 순서:
1. 지정된 제출 위치·파일명·필수 산출물
2. 실행 방법과 실제 재실행 가능 여부
3. 핵심 결과의 정확성 및 중요한 오류
4. 필수 조건별 완료·미확인·미완료 상태
5. 실행 안내와 구현 사실의 일치
6. 남은 한계와 제가 설명해야 할 선택

이 단계에서는 새로운 선택 기능을 추가하지 말고,
실행·제출을 막는 문제와 필수 조건의 오류에 집중해주세요.
실제로 확인한 내용만 완료로 표시하고, 수정했다면 필요한 검사를 다시 수행해주세요.

최종적으로 제가 확인할 제출 항목을 짧게 알려주세요.
파일 검사나 메모 작성만으로 플랫폼 제출이 완료됐다고 말하지 마세요.
~~~
