# 결과물 검토 요청

~~~text
현재 결과물을 실제 과제 요구사항과 대조해 검토해주세요.
우선 읽기와 재현 가능한 확인에 집중하고, 지적마다 근거를 제시해주세요.

확인할 내용:
1. 빠진 필수 요구사항
2. 잘못된 결과를 만드는 입력
3. 중요한 오류·빈 입력·경계 상황
4. 검증이 부족하거나 기록과 코드가 다른 부분
5. 실행·제출을 막는 문제

각 지적은 아래처럼 정리해주세요.
- 위치와 증상
- 재현 방법 또는 구체적 근거
- 사용자에게 미치는 영향
- 지금 수정할지, 이후 개선할지
- 확인해야 할 최소 검사

문제를 발견하지 못한 부분과 실제로 검증한 부분을 구분해주세요.
근거 없는 문제를 만들거나 전체 구조를 바꾸는 제안부터 하지 마세요.
~~~
