# 요구사항 확인 요청

~~~text
현재 과제 설명과 담당자 답변을 바탕으로 요구사항을 정리해주세요.

- 확인된 사실과 근거
- 아직 확인하지 못한 사항
- 필수 기능과 선택 기능
- 각 필수 기능의 입력·기대 결과·중요한 예외
- 구현이나 검증을 실제로 바꿀 질문 최대 5개

업무 규칙을 추측해 확정하지 마세요.
질문마다 답변에 따라 무엇이 달라지는지 한 줄로 적어주세요.
제가 알고 있는 배경이 필요한 부분은 저에게 구체적으로 질문해주세요.
~~~

업무 담당자에게 보낼 질문은 실제 업무 사실에 집중합니다. 내부 구현 선택을 모두 담당자에게 넘길 필요는 없습니다.
