# 구현 설명 연습 요청

**AI 사용이 허용된 과제 수행 단계에서만 사용합니다. 후속 서술형 단계에서는 사용하지 않습니다.**

~~~text
현재 제출물의 핵심 코드와 실제 작업 기록을 읽고 설명 연습을 도와주세요.

먼저 입력 → 처리 → 출력 흐름을 파일·함수 역할과 연결해 짧게 정리해주세요.
그다음 아래 관점에서 제 구현을 근거로 질문 6개를 만들어주세요.
- 선택한 구조와 이유
- 다른 방법과의 장단점
- 실제 검증한 내용
- 실패 가능성과 남은 한계
- 추가 시간이 있을 때의 확인 순서

처음부터 모범 답변을 길게 제공하지 말고 제가 답할 수 있게 질문을 먼저 주세요.
제가 답하면 실제 코드·기록과 일치하는지, 근거가 빠졌는지 검토해주세요.
수행하지 않은 작업을 수행한 것처럼 설명하도록 유도하지 마세요.
~~~
